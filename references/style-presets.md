# Style presets

Use one preset per pack. Preserve the same identity, proportions, clothing, palette, line treatment, lighting, and outline across all nine cells.

1. **3D animated sticker** — rounded stylized proportions, soft studio lighting, smooth materials, expressive face, polished family-friendly animation look; do not reference a named studio or franchise.
2. **Japanese manga** — clean ink lines, cel shading, expressive eyes, restrained highlights, modern generic manga treatment; do not imitate a named artist or title.
3. **Hand-drawn watercolor** — visible paper texture, soft watercolor washes, delicate pencil outline, warm handmade feeling.
4. **Pixel art** — crisp pixel clusters, limited palette, readable silhouette, consistent pixel density, no anti-aliased edges.
5. **Clay figure** — handmade clay texture, rounded forms, soft shadows, miniature stop-motion feeling.
6. **Cyberpunk neon** — dark base, cyan and magenta rim lights, subtle holographic accents, clear face and readable silhouette.
7. **Flat vector** — bold geometric shapes, limited palette, clean contours, minimal shading, icon-like readability.
8. **Retro print** — muted vintage palette, halftone grain, slightly imperfect ink registration, clean central silhouette.
9. **Soft crayon** — waxy crayon texture, pastel palette, friendly uneven strokes, simple forms.
10. **Felt doll** — layered felt texture, visible stitched edges, soft fabric volume, handcrafted toy appearance.

When the user provides a different style, translate it into visual attributes. Avoid copying a living artist's signature style, branded character, or protected franchise identity.
