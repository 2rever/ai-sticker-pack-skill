PersonaStickerSkill｜AI 表情包生成技能
只需要上传一张人物照片，就能生成一套统一形象、透明背景的九宫格表情包。
这个 Skill 封装了从人物特征提取、画风选择、九宫格生成、局部修改，到单张 PNG 切分的完整流程。适合制作聊天表情、个人 IP、社交头像、贴纸和周边素材。
功能特点
- 一张照片生成一套 3×3 九宫格表情包
- 自动保留脸型、发型、眼镜、五官比例和服装特征
- 默认生成九种不同的情绪和动作
- 支持十种预设画风
- 支持透明背景和统一白色贴纸描边
- 一次生成，只产出透明背景版本，不会先生成白底或预览版再生成第二次
- 只展示一次：质检和修复在展示前完成，失败草稿不会发给你
- 支持只修改九宫格中的某一格
- 支持无文字版和文字版表情包
- 支持把九宫格切成九张独立 PNG 图片
- 可继续延展为动态表情、个人 IP 和桌面宠物素材
默认情绪
如果没有指定表情内容，Skill 默认生成以下九种情绪：
1. 开心
2. 无语
3. 收到
4. 感谢
5. 加油
6. 震惊
7. 生气
8. 偷笑
9. 晚安
情绪、动作和排列顺序都可以自行修改。
支持的画风
目前内置十种画风：
1. 3D 动画贴纸风
2. 日系漫画风
3. 手绘水彩风
4. 像素风
5. 黏土玩偶风
6. 赛博朋克霓虹风
7. 扁平矢量风
8. 复古印刷风
9. 柔和蜡笔风
10. 毛毡玩偶风
为了保证整套表情包统一，每次生成只使用一种画风，不会在同一个九宫格里混合多种风格。
如何使用
方法一：通过 GitHub 导入
复制本仓库地址：
https://github.com/2rever/ai-sticker-pack-skill
打开支持 GitHub Skill 的 AI 客户端，进入工作模式，然后让 AI 安装或加载这个仓库中的 Skill。
不同客户端的导入入口可能有所不同，请以客户端当前版本的界面为准。
方法二：下载到本地
点击仓库右上角的 Code，选择 Download ZIP，解压后导入完整的 Skill 文件夹。
不要只下载 SKILL.md，因为完整功能还会使用 references、scripts 和 agents 文件夹中的内容。
推荐指令
加载 Skill 后，上传一张人物照片，然后发送：
使用 $PersonaStickerSkill 把这张人物照片制作成透明背景的九宫格表情包。
也可以加入自己的要求：
使用 $PersonaStickerSkill 把这张照片制作成3×3九宫格表情包。

选择日系漫画风，保留人物的脸型、短发、黑框眼镜和黑色上衣。九种情绪分别是开心、无语、收到、感谢、加油、震惊、生气、偷笑和晚安。

统一使用透明背景和白色贴纸描边，不要添加文字、水印、乱码或多余人物。只生成一次透明背景版本，不要先生成白底或预览版再生成第二次。
照片选择建议
为了让生成的人物更像原照片，建议使用：
- 正脸或接近正脸的照片
- 光线清楚、曝光正常的照片
- 五官没有被头发、口罩或手遮挡
- 发型、眼睛、脸型和眼镜清晰可见
- 图片分辨率足够，不要使用严重模糊的照片
- 尽量只出现一个人物
照片中的特征越清楚，生成结果通常越稳定。
请确保你有权使用上传照片中的人物肖像。
局部修改
如果只有某一格不满意，不需要重新生成整套表情包。
例如正中间的“加油”表情不符合要求，可以发送：
保持其他八格的人物形象和画风不变，只修改正中间一格。

把正中间改成双手握拳举起加油的表情，保留原来的脸型、发型、眼镜、服装、配色、透明背景和白色描边，不要修改其他格子。
局部修改通常比重新生成整套更加稳定，也更容易保持人物形象一致。
添加文字
建议先生成并确认无文字版本，再单独制作文字版本。
示例指令：
基于已经确认的无文字表情包生成文字版，保持人物形象、动作和画风不变。

按照九宫格顺序分别加入：哈哈哈、无语、收到、谢谢老板、加油、真的假的、生气了、偷偷笑、晚安。

统一使用清晰的圆润字体，不要遮挡人物的脸和手，保持透明背景和白色描边。
生成后需要重点检查：
- 有没有错别字
- 有没有乱码
- 字体风格是否统一
- 字号大小是否协调
- 文字有没有遮挡人物
- 九格文字是否与情绪对应
图片生成模型处理中文时可能出现错误，因此建议始终保留一份无文字母版。
切分九宫格
表情包确认后，可以让 AI 把九宫格拆分成九张独立图片：
把确认后的九宫格表情包切分成九张独立的PNG图片，按照从左到右、从上到下的顺序编号。

保留透明背景和完整的白色描边，不要裁到人物，也不要让相邻格子的内容残留在图片中。
仓库也提供了确定性切图脚本：
python3 scripts/split_sticker_grid.py master.png output-dir \
  --rows 3 \
  --cols 3 \
  --require-alpha \
  --trim
脚本依赖 Pillow：
pip install Pillow
运行完成后，输出目录中会包含九张独立 PNG 图片和一份切分记录文件。
质量检查
完成后建议检查以下项目：
- 是否正好包含九种需要的情绪
- 九格是否为同一个人物
- 发型、眼镜、脸型和服装是否统一
- 画风、配色和光线是否一致
- 每个表情是否完整且相互独立
- 有没有裁到头发、手部或白色描边
- 背景是否真的透明
- 有没有水印、乱码或多余人物
- 拆分后的九张图片能否单独正常打开
- 每张图片中是否残留相邻格子的内容
白色背景不等于透明背景。如果导出的图片没有 Alpha 透明通道，需要重新生成或进行背景移除处理。
动态表情与桌面宠物
确认静态表情以后，可以继续选择其中几张生成简单动态效果，例如：
- 眨眼
- 挥手
- 点头
- 跳动
- 鼓掌
- 生气跺脚
- 闭眼睡觉
需要注意：九宫格表情包只是制作桌面宠物的基础素材，并不等于已经完成了桌面宠物。
一套真正可用的桌面宠物通常还需要：
- 透明背景的全身基础角色
- 待机动画
- 行走动画
- 点击和拖拽反应
- 睡觉、开心、生气等状态
- 不同状态之间的过渡动画
- 用于运行桌面宠物的应用程序
